# CodeAlpha EDA

## Project Overview
Exploratory Data Analysis of a books dataset using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Dataset overview
- Missing value analysis
- Duplicate value checking
- Price analysis
- Availability analysis
- Rating analysis
- Top 5 expensive books
- Top 5 cheapest books
- Book rating distribution visualization

## Dataset
The dataset contains book titles, prices, availability, and ratings.

## Output
A bar chart showing the distribution of book ratings is included in the repository.
